# Вариант 6 — этап 1 (REPL)

Минимальный консольный эмулятор UNIX-оболочки на Python 3.

## Запуск

В PowerShell из папки проекта:

```powershell
py main.py
```

## Демонстрация работы

Введите команды по очереди:

```text
ls
ls -l
cd documents
cd one two
ls $USERNAME
unknown
exit 1
exit
```

Проверяется: вывод приглашения из имени пользователя и компьютера, раскрытие переменной окружения, заглушки ls и cd, ошибки неверных аргументов и неизвестных команд, завершение через exit.

Команды `ls` и `cd` **не работают с файлами и папками**: на первом этапе они только показывают название и аргументы.

На Windows переменная `$USERNAME` обычно существует. Для проверки другой переменной можно использовать `$USERPROFILE`.

## Сохранение этапа в Git

В папке проекта выполнить:

```powershell
git init
git add main.py README.md
git commit -m "Implement stage 1 REPL for variant 6"
```

Коммит необходимо сделать в своём репозитории самостоятельно.
