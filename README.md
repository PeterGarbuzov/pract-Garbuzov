# Эмулятор UNIX-оболочки — вариант 6, этап 5

Финальный этап добавляет команду `rmdir` к командам `ls`, `cd`, `head`, `cat`, `exit`.
Все операции с VFS выполняются **только в оперативной памяти**. JSON-файлы
на диске не изменяются.

## Запуск (Windows)

```powershell
py main.py --vfs vfs_rmdir.json --script startup_rmdir.txt
```

Или дважды нажмите `test_rmdir.bat`.

## Новая команда

- `rmdir каталог` — удалить пустой каталог.
- `rmdir каталог1 каталог2` — последовательно удалить несколько каталогов.
- Поддерживаются абсолютные и относительные пути, `.` и `..`.
- Нельзя удалить корень `/`, непустой каталог, файл, текущий каталог или
  родительский каталог текущего пути.
- Ошибки выводятся на экран, дальнейшие команды стартового скрипта
  продолжают выполняться.

В `startup_rmdir.txt` есть успешные и ошибочные примеры `rmdir`, а также
проверки прежних команд. `vfs_rmdir.json` содержит пустые каталоги,
непустые каталоги и текстовый файл.

## Прочие команды

- `ls [путь...]`, `ls -l [путь...]` — показать содержимое каталога.
- `cd [путь]` — сменить текущий виртуальный каталог.
- `cat файл [файл...]` — вывести текст файла.
- `head [-n число] файл [файл...]` — вывести первые строки файла.
- `exit` — завершить работу.
